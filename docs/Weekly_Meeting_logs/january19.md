### **Next Week’s Targets**

1. **User Feedback Module**

   * Implement a feedback system where users can rate a specific day’s menu based on their previous orders.
   * Users will be able to submit a numerical rating along with a short comment as a remark.

2. **Ratings During Ordering**

   * While placing an order, users will be shown the **average rating** of the menu for that particular day.
   * Alongside the rating, the **number of users who have submitted ratings** will be displayed in brackets to provide better context and credibility.

3. **Overall Menu Ratings (User View)**

   * Provide an interface for users to view the **overall ratings of menus across all days**, enabling them to compare and assess menu quality over time.

4. **Admin Dashboard Enhancements**

   * Enable administrators to view the **overall ratings for each day’s menu**.
   * Display individual user remarks and comments associated with those ratings for better qualitative insights.
